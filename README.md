# Супертоника или Верхний (нисходящий) вводный тон

В этом уроке 12 упражнений, все в разных случайных тональностях.

В первых трёх упражнениях нижняя нота - <span class="q-pa-xs bg-tonic text-white">Тоника</span> (1 ступень). 

В следующих трёх - <span class="q-pa-xs bg-supertonic text-white">Супертоника</span> (2 ступень).

В следующих трёх - <span class="q-pa-xs bg-subdominant text-white">Субдоминанта</span> (4 ступень).

В следующих трёх - <span class="q-pa-xs bg-dominant text-white">Домиинанта</span> (5 ступень).
